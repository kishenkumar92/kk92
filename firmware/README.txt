OTA Firmware Folder
====================

Files in this folder are used for remote over-the-air (OTA) updates.

version.txt
-----------
Contains the current firmware version string.
Must match FW_VERSION in ESP32_Dummy_v1.ino exactly.
Example: paradise-esp32-dummy-2.2

paradise-dummy.bin
------------------
The compiled firmware binary.
Generated by PlatformIO build (.pio/build/esp32dev/firmware.bin).

HOW TO RELEASE A NEW VERSION
------------------------------
1. Edit ESP32_Dummy_v1.ino — bump FW_VERSION e.g. "paradise-esp32-dummy-2.3"
2. In VS Code: Ctrl+Alt+B to build
3. Copy .pio/build/esp32dev/firmware.bin to this folder as paradise-dummy.bin
4. Update version.txt to match the new FW_VERSION
5. git add . && git commit -m "Release vX.X" && git push
6. ESP detects new version within 1 hour and self-updates automatically
